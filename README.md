### 定义

胃肠间质瘤（GIST）是起源于消化道间叶组织、通常与 Cajal 间质细胞相关的肿瘤，与上皮来源的「癌」不属于同一类。因此本台不用 TNM 作默认结构，而把「病理四事实 + 危险度」放在最前面。

最常见部位为胃（50–70%），其次小肠（20–30%）；结直肠、食管、网膜少见，部位必须单列，因为不同危险度体系按部位给不同阈值。分子主轴：KIT 突变约 70–80%（exon 11 最常见，exon 9 约 10–15%）、PDGFRA 约 5–8%、野生型约 10–15%（SDH 缺陷、NF1、BRAF、NTRK 等），外显子编号照报告原文抄，本台不推断。

**危险度分级与分期是两套东西**：GIST 常用改良 NIH（Fletcher）与 AFIP-Miettinen 等危险度体系，按肿瘤大小 + 核分裂数（AFIP 另加部位）分级；本台不把危险度当 TNM，也不在两套体系之间换算、不取最高。肿瘤破裂（术前自发或术中）独立于危险度体系记录，不与任何一级混写。转移以肝转移与腹膜播散为主，淋巴结转移少；本台不设「淋巴结分期」结构。GIST 没有公认的血清肿瘤标志物；CEA / CA19-9 / SCC 不进默认指标集，LDH 只作普通化验记录。

### 目前治疗全景概要

下面按期别与线序列出指南里出现过的手段类别。这是「世界上大致有哪些办法」的地图，不是给你排的先后顺序，也不含任何剂量、疗程与适用条件。

- **局限期（可以完整切除时）**：手术以完整切除（R0）为目标，同时避免肿瘤破裂，一般不常规清扫淋巴结；部分局部进展、需要缩小体积的情形先做术前靶向治疗，本台按「术前 / 术后」阶段分开记录；EFTR / ESD 等内镜术式出现在在研登记里，适用条件按内镜与病理评估决定。
- **术后辅助**：高危常规 3 年 TKI；极高危（含破裂、非胃来源高核分裂等情形）可考虑延至 5–6 年。复查按高危切除后前 2–3 年每 3–4 个月腹盆增强 CT、第 4–5 年每 6 个月、之后每年至 10 年记录。
- **晚期 / 转移后（线序）**：一线伊马替尼；二线舒尼替尼；三线瑞戈非尼；四线瑞普替尼。特殊分子亚型单列：PDGFRA D842V 对应阿伐替尼，SDH 缺陷型对应舒尼替尼 / 瑞戈非尼等；本台只并列记录，不比较优劣。指南把「参加登记良好的临床试验」列为一项正式选项。
- **贯穿全程**：剂量变更每次一行（从多少到多少 + 医生原话理由），漏服按天记事实、不算依从率；副作用按 CTCAE 原文分级照抄；晚期用药中每 2–3 个月影像评估，影像结论抄原文、不做疗效评价。

> 以上是文献与指南里列出的手段，按病期与线序排列，不代表任何一项适合你。选哪一个，这一句需要问你的医生。

## 怎么打开

```bash
# 原型（纯静态，直接开文件即可）
open prototypes/v0.2/index.html

# 开发版（走真实 API，起本地服务）
NODE_OPTIONS= node scripts/dev-server.mjs --workspace ~/Documents/GistPalWorkspace --port 4173 --open
```

`--workspace` 必填且必须是你自己新建的目录；主目录、桌面/下载根、`/tmp`、`/var` 会被拒绝，
**不会静默建目录**。
