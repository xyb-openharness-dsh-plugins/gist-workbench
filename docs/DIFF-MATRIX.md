用途：证明「小吉宝」不是把小咽宝换文案，而是按癌种的临床结构重排了信息。
对照对象：`colorectal-workbench`（结直肠）、`gastric-workbench`（胃）、`esophageal-workbench`（食管）。

## 三个"看起来像、其实不同"的地方

1. **一图秀都画三条线，但不是同三条。** 结直肠是 CEA+体重+体力，食管是体重+白蛋白+吞咽分级，
   GIST 是 Hb+体重+乏力。共同点只是"两条数值线 + 一条分类节点"，分类都不连线。
2. **都有"用药"内容，只有 GIST 单开一级页。** 其它癌种的用药是"某段治疗的组成部分"；
   GIST 的 TKI 是**连续数年、按月调剂量、副作用天天在**的独立生活事实，混进治疗历程会丢细节。
3. **都有危险度，只有 GIST 是多套并存。** 其它癌种的分期是单一体系（TNM）；GIST 的 Fletcher / AFIP /
   国内共识三套阈值不同，同一份病理可能给出两个级别，所以必须并列而不是"取一个"。
