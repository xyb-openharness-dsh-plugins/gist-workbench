# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：胃肠间质瘤（GIST）患者及家属照护者；术后辅助治疗期、晚期靶向治疗期与长期随访期人群

场景：病理与基因型档案（部位/大小/核分裂/CD117/DOG1/KIT/PDGFRA）、危险度分级记录、手术与术前术后靶向路径、伊马替尼与后线TKI用药及副作用、腹部影像复查节奏、消化道出血与症状记录、复诊准备

核心流程：
1. 选择本机资料目录并导入病理、基因检测、影像与出院记录
2. 核对候选信息，建立病理与危险度档案
3. 记录手术、靶向治疗路径与用药副作用
4. 整理复查影像与指标趋势
5. 生成复诊准备材料

完成结果：得到来源可追溯、可核对的个人病程档案：病理与危险度依据、治疗路径与线序、用药与副作用趋势、影像复查记录、就诊准备材料；候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
