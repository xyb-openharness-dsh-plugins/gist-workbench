## 风险与对策

| 风险 | 表现 | 对策 |
| --- | --- | --- |
| 危险度被当结论 | 用户以为页面给的级别是诊断 | 每套体系都带 `source`，页脚常驻"由医生给出" |

| 一图秀点太密 | 14 个点挤在半年 | 末点 13px 避让 + 单点不连线 + 分类只画节点 |
| 长程数据疲劳 | 辅助期第 3 年不再记录 | 看板只留三张卡；录入路径最多两步 |
