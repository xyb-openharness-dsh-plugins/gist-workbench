# GIST 临床数据与口径（2026-10）

本文件是工作台**字段与时间粒度**的依据，不是科普材料，也不复述指南推荐。
所有条目的用途只有一个：决定工作台记什么、按什么粒度记、哪些值必须留原文。

指南基线：**NCCN GIST v1.2026**（2026-01-13 更新）、**CSCO 胃肠间质瘤诊疗指南 2025**。
资料包：`research/gist-cancer/`（16 条 2026 年首次公示的干预性试验，口径与限制见该目录 README）。

## 1. 疾病事实（决定默认字段）

| 事实 | 数据 | 对工作台的含义 |
| --- | --- | --- |
| 起源 | 消化道间叶源性肿瘤，起源于 Cajal 间质细胞 | 与癌（上皮来源）不同，不用"分期 TNM"作默认结构 |
| 最常见部位 | 胃 50–70%，小肠 20–30%，结直肠/食管/网膜少见 | 部位必须单列（危险度体系按部位给不同阈值） |
| 分子主轴 | KIT 突变 ~70–80%（exon 11 最常见，exon 9 约 10–15%）；PDGFRA ~5–8%；野生型 ~10–15%（SDH 缺陷、NF1、BRAF、NTRK 等） | 分子页必须有 exon 9 / exon 11 / exon 18 D842V / SDH / NF1 五个记录位 + NGS 备注位 |
| 转移方式 | 肝转移 + 腹膜播散为主；淋巴结转移少 | 影像记录位以腹盆 CT/MRI 为主，不设"淋巴结分期"结构 |
| 出血 | 黏膜下肿瘤易溃破出血，黑便/呕血是常见首发 | 出血与急症独立页签（SPEC A10） |
| 血清标志物 | **无公认的 GIST 血清肿瘤标志物** | 指标集不含 CEA/CA19-9/SCC；LDH 归生化（SPEC §2.13） |

## 2. 危险度分级：三套体系并存

同一份病理在不同体系下可能落到不同级别，**工作台不选体系、不重算、不取最高**。

| 体系 | 参数 | 结构 | 备注 |
| --- | --- | --- | --- |
| Fletcher / NIH 2008 修改版 | 肿瘤大小 + 核分裂数（/50 HPF） | 极低 / 低 / 中 / 高 四级 | 最常用、最便于沟通；不含部位 |
| AFIP-Miettinen | 部位 + 大小 + 核分裂数 | 胃与非胃**阈值不同** | 同样大小核分裂，小肠比胃风险高，所以部位必须单列 |
| 中国 GIST 共识 2017 修改版 | 部位 + 大小 + 核分裂数（+ 破裂） | 极低 / 低 / 中 / 高 | 国内报告常用；阈值与 AFIP 接近但不完全一致 |

**数据模型对应**：`risk_rows` 一行一套体系，字段 `system / grade / basis / source / note`。
`grade` 存**报告或医生给的分级原文**，`basis` 存该体系用的参数原值，`source` 存报告名或医生原话。
`risk_rows` 至少两行；只有一行时页面提示"还有体系没记录"，不替用户补。

**肿瘤破裂**：术前自发破裂或术中破裂，独立于上述三套体系，等同腹腔播散风险。
工作台把它放在 `surgery_rows.rupture`，与 `margin` 并列，不与危险度混写。

## 3. 治疗结构与线序（决定治疗历程页的形状）

| 阶段 | 结构 | 工作台记录位 |
| --- | --- | --- |
| 术前治疗 | 部分局部进展/需缩小体积者先做 TKI | `pathway_rows`（phase=当前/既往） |
| 手术 | 完整切除（R0），避免破裂；一般不常规清扫淋巴结 | `surgery_rows`：术式 / 切除范围 / 切缘 / 破裂 / 机构 |
| 术后辅助 | 高危常规 3 年；极高危（含破裂、非胃来源高核分裂）可考虑延至 5–6 年 | `med_rows` + `cycles`（起止与完成度） |
| 晚期一线 1L | 伊马替尼 | `treatment_lines` 第 1 行 |
| 二线 2L | 舒尼替尼 | 第 2 行 |
| 三线 3L | 瑞戈非尼 | 第 3 行 |
| 四线 4L | 瑞普替尼 | 第 4 行 |
| 特殊分子亚型 | PDGFRA D842V → 阿伐替尼；SDH 缺陷型 → 舒尼替尼/瑞戈非尼等 | 分子页与线序页交叉引用，**工作台不给选药建议** |

线序页只呈现"事实顺序 + 起止 + 换线理由（医生原话）"，不做药物比较、不标"优选"。

## 4. 随访与复查（决定复查节奏页与影像页）

| 场景 | 频率（指南层面） | 工作台怎么记 |
| --- | --- | --- |
| 高危切除后前 2–3 年 | 每 3–4 个月腹盆增强 CT | `monitor_rows` 一行一个项目，`freq` 存医生给的间隔原文 |
| 第 4–5 年 | 每 6 个月 | 同上 |
| 之后 | 每年，至 10 年 | 同上 |
| 晚期用药中 | 每 2–3 个月影像评估 | 同上 |

**关键约束**：工作台**不生成统一随访表**，只显示"医生给的间隔 + 上次 + 下次"。
指南频率只在文档里出现，页面不写"你应该每 3 个月复查"。

### 5.2 非药物类线索（同样重要，决定"临床研究"页的展示口径）

- 手术/内镜技术类：EFTR vs STER（NCT07411118）、新型双齿夹用于 GIST 的 ESD/EFTR（NCT07581977）、

## 7. 这些数据怎么进工作台

- `trials` 表只存 6 个字段（`nct_id / title / phase / status / sponsor / url`），**不存 summary 与 eligibility**，
  避免页面变成"试验推荐器"。
- 演示数据里放 3–5 条与本癌种相关、状态各异的记录，够看清结构即可。
- 资料包（jsonl + sqlite）留在 `research/`，不打包进 `public/`，不进产物 tgz。
