## 1. 目标与非目标

**目标**：让胃肠间质瘤患者（及照护者）在门诊十几分钟里把四件事说清楚、带进去：

1. 我的病理事实是什么——部位、大小、核分裂数、**肿瘤破裂**、切缘，以及**医生用哪套体系给的几级危险度**？（**病理与危险度**）
2. 我在吃哪个靶向药、什么剂量、吃到第几个月，中间为什么减量或停过？漏过几次、副作用到几级？（**靶向用药**）
3. 治疗走到哪一步：术前靶向 / 手术 / 术后辅助 / 晚期一线二线三线四线？（**治疗路径与线序**）
4. 指标与影像怎么变——血红蛋白、体重、乏力分级，CT/MRI 结论原文怎么写的，下次复查约在什么时候？（**一图秀 + 检查与指标**）

**非目标**（明确不做）：

- 不做诊断、不做病理判读、不做危险度重算（不拿大小 × 核分裂数自己算分级）
- 不判断"要不要手术""要不要停药""能不能减量"，不给剂量建议，不比较药物优劣
- 不解读影像（不测量病灶、不判 PR/PD）、不给疗效评价
- 不做营养处方、不给食谱、不换算热量
- 不推荐医院/医生，不做病友匹配，不做预后预测

## 2. 产品立场

继承家族 9 条立场（见 `docs/LESSONS.md` 与结直肠癌 SPEC §2）。GIST 追加 4 条：

10. **危险度是多套并存的记录，不是一个算出来的数字。**
    NCCN v1.2026 同时保留 Fletcher/NIH 2008 修改版与 AFIP-Miettinen 两套体系，国内共识另有 2017 修改版；
    同一份病理在不同体系下可能落在不同级别。工作台**一行一个体系**并列呈现，标清依据与来源，
    不合并、不取最高、不替医生选体系。
11. **分子分型是治疗决策的输入，不是工作台的结论。**
    工作台只记录报告原文的四态：已出结果 / 未检测 / 需关注 / 待出。**未检测绝不写成"阴性"**，
    外显子编号照报告抄（`exon 9`、`exon 11`、`exon 18 D842V`），不由工作台推断"应该是哪个外显子"。
12. **肿瘤破裂单列成字段。**
    破裂（术前/术中）在 GIST 里是独立且权重极高的预后事实，等同腹腔播散风险；埋进备注等于丢信息。
13. **GIST 没有公认的血清肿瘤标志物。**
    CEA / CA19-9 / SCC 一类不进入默认指标集；LDH 只作普通化验记录，**不标注为"肿瘤标志物"**。
    这条直接决定一图秀默认三条线是**血红蛋白 + 体重 + 乏力分级**，而不是"标志物 + 影像"。

## 3. 范围（一期）

| # | 模块 | 内容 | GIST 差异点 |
| --- | --- | --- | --- |
| 1 | 看板 | 定调条 →「现在可以做」→ **危险度卡** / **当前靶向药卡** / **下一次影像卡** → 接下来 / 最近变化 | 危险度卡为首卡，多体系并列缩略 |
| 2 | 病情整理 | 资料库 / 整理草稿核对 / 病情档案 / 指标检测 / 病情汇总（五段沿用家族骨架） | 解析重点：病理报告、基因检测报告、影像报告 |
| 3 | **病理与危险度（独立一级页）** | ① 病理与免疫组化（CD117/DOG1/核分裂/大小/部位/切缘/破裂 + 报告未写的待补位）② **危险度分级（多套体系并列）** ③ 分子与基因（KIT/PDGFRA/SDHB/NF1/NGS 四态） | 本癌种信息密度重心 |
| 4 | 治疗历程 | ① 治疗路径与线序（术前靶向 / 手术 / 术后辅助 / 晚期 1L–4L / 局部处理）② 手术记录（术式/切除范围/切缘/**破裂**/机构）③ 疗程与周期 | "线序"是 GIST 的核心结构 |
| 5 | **靶向用药（独立一级页）** | ① 当前用药 ② 剂量变更（时间轴 + 医生原话理由）③ 服药与漏服（按天记事实）④ 副作用记录（CTCAE 分级原文 + 实际处理） | 长期 TKI 是主要生活负担 |
| 6 | 检查与指标 | ① 血象与生化 ② **药物浓度（伊马替尼谷浓度）** ③ 影像与复查（结论原文 + 下次安排） | 药物浓度是 GIST 特有记录位 |
| 7 | 病情一图秀 | 治疗节点 + 血红蛋白 / 体重（数值线）+ 乏力（分类节点，不连线） | 默认三条线由 GIST 随访逻辑决定 |
| 8 | 生活与营养 | ① 进食记录 ② 体重与营养 | 不设"吞咽通路"（那是食管癌） |
| 9 | 心理支持 | ① 当下感受 ② 用药与身体（长期吃药、水肿、疲乏）③ 家庭沟通 | 长期 TKI 的身体意象议题 |
| 10 | 复诊准备 | ① 复查节奏 ② **出血与急症** ③ 就诊准备 | GIST 易出血，急症记录位独立 |
| 11 | 临床研究 | 2026 线索 / 已收藏 / 入组问题 | 骨架 |
| — | 设置 | 同骨架 | 骨架 |

### 明确不做

危险度自算、疗效评价（PR/PD）、剂量建议、换药建议、停药建议、复发风险百分比预测、
影像测量、病理切片解读、"能不能手术"判断、营养液/保健品推荐、病友匹配。

## 4. 信息架构（11 个一级页 / 32 个二级页签）

```
看板
病情整理 ── 资料库 / 整理草稿核对 / 病情档案 / 指标检测 / 病情汇总
病理与危险度 ── 病理与免疫组化 / 危险度分级 / 分子与基因
治疗历程 ── 治疗路径与线序 / 手术记录 / 疗程与周期
靶向用药 ── 当前用药 / 剂量变更 / 服药与漏服 / 副作用记录
检查与指标 ── 血象与生化 / 药物浓度 / 影像与复查
病情一图秀 ── 数值曲线 / 分类与事件 / 数据口径
生活与营养 ── 进食记录 / 体重与营养
心理支持 ── 当下感受 / 用药与身体 / 家庭沟通
复诊准备 ── 复查节奏 / 出血与急症 / 就诊准备
临床研究 ── 2026 线索 / 已收藏 / 入组问题
```

差异自查（对照家族其它癌种）：

- 独有「病理与危险度」「靶向用药」两个一级页 —— 其它癌种把用药并进"治疗历程"；
  GIST 因为**辅助治疗长达 3–6 年、剂量调整频繁、副作用是日常**，必须独立。
- 「治疗历程」以**线序**开局（1L 伊马替尼 → 2L 舒尼替尼 → 3L 瑞戈非尼 → 4L 瑞普替尼），
  与食管癌的"路径三选一"不同构。
- 没有「吞咽与进食通路」页；营养退化为两页签的轻结构。
- 一图秀默认序列是 Hb + 体重 + 乏力，**不含任何肿瘤标志物**（§2 第 13 条）。

## 5. 特有场景

| # | 场景 | 给什么 | 不给什么 |
| --- | --- | --- | --- |
| G1 | 术后拿到病理，医生说"高危，要吃三年药" | 四个独立事实（大小/核分裂/部位/破裂）+ 多套体系分级并列 + 医生原话 | 不解释"为什么是高危"、不给复发概率 |
| G2 | 辅助期第 18 个月，想减量 | 剂量变更时间轴（每次减量的日期与理由）+ 副作用分级序列 | 不建议减/不减、不判断"能不能停" |
| G3 | 复查 CT 说"术区稳定" | 影像结论原文按时间排 + 下次安排 | 不解读"稳定"、不做疗效评价 |
| G4 | 基因报告写 KIT exon 9 | 分子四态卡片（原值 + 来源 + 状态） | 不说"所以要加量到 800" |
| G5 | 出现黑便 | 出血事件记录（日期/表现/处理经过/是否急诊） | 不判严重度、不给居家处理建议 |
| G6 | 晚期进展，医生换二线 | 线序结构 + 换线日期与理由留痕 | 不比较二线药物优劣 |
| G7 | 想找临床试验 | 2026 线索 + 入组问题清单 | 不排序、不预测获益 |

## 6. 验收（A 条目要点）

| # | 条目 |
| --- | --- |
| A1 | 病理四事实（大小/核分裂/部位/破裂）各自独立字段，任一缺失显示"报告未写"而**不是 0 / 阴性** |
| A2 | 危险度**至少两套体系并列**，每套标 `体系 / 分级原文 / 依据参数 / 来源`；不合并、不取最高 |
| A3 | 治疗路径切换只新增 `phase=既往`，旧路径不删除、可回溯 |
| A4 | 手术记录中「肿瘤破裂」为独立字段，可与「切缘」分别取值 |
| A5 | 剂量变更每次一行，含 `from → to + 理由（医生原话）`，历史剂量不被覆盖 |
| A6 | 服药记录只存"按计划 / 漏服 / 减量"事实，界面**不出现依从率百分比** |
| A7 | 副作用分级照 CTCAE 原文（1–4 级），不换算、不合并症状 |
| A8 | 影像 `finding` 抄结论原文，界面不出现"好转/恶化/有效/无效"等评价词 |
| A9 | 复查节奏只显示医生给的间隔与下次日期，不生成统一随访表 |
| A10 | 出血事件独立成节，含日期 / 表现 / 处理经过 / 是否急诊 |
| A11 | 分子检测四态；`na`（未检测）不得渲染为"阴性"；外显子编号照原文 |
| A12 | 一图秀默认 Hb + 体重（数值线）+ 乏力（分类节点不连线）；分类单点写"只有 1 次记录，暂不连线" |
| A13 | 指标区**不出现 CEA / CA19-9 / SCC**；LDH 不标"肿瘤标志物" |
| A14 | 文案红线：不出现"建议治疗/可能复发/可以停药/无需就医/推荐方案/治愈率/生存率" |
| A15 | 看板首卡是危险度卡，"现在可以做"三条动作可点且落到对应页 |

## 7. 术语

| 术语 | 含义 |
| --- | --- |
| GIST | 胃肠间质瘤（Gastrointestinal Stromal Tumor），最常见的消化道间叶源性肿瘤 |
| CD117 / DOG1 | 免疫组化标志物，GIST 常用；阳性率约 95% / 98% |
| 核分裂象（/50 HPF） | 每 50 个高倍视野的核分裂计数，危险度分级核心参数 |
| Fletcher / NIH 2008 修改版 | 按大小 + 核分裂数分级（极低/低/中/高） |
| AFIP-Miettinen | 按部位 + 大小 + 核分裂数分级，胃与非胃阈值不同 |
| 中国 GIST 共识 2017 修改版 | 国内常用危险度分级，参数与 AFIP 接近但阈值有差异 |
| 肿瘤破裂 | 术前自发或术中破裂，等同腹腔播散风险，独立高危因素 |
| 辅助治疗 | 根治术后用 TKI 降低复发；高危常规 3 年，极高危可延至 5–6 年 |
| 线序（1L–4L） | 晚期/转移的用药顺序：伊马替尼 → 舒尼替尼 → 瑞戈非尼 → 瑞普替尼 |
| TKI | 酪氨酸激酶抑制剂 |
| 谷浓度（Cmin） | 服药间隔末的血药浓度，伊马替尼常记 `ng/mL` |
| CTCAE 分级 | 不良事件通用术语标准分级（1–4 级），照报告抄，不自行换算 |
| SDH 缺陷型 | 野生型 GIST 亚型，对伊马替尼不敏感，需单独记录 |
| D842V | PDGFRA exon 18 突变，对伊马替尼原发耐药，指南单列 |

## 8. 指南依据与边界

- **NCCN GIST v1.2026**（2026-01-13 更新）：危险度多体系并存；高危辅助伊马替尼 400 mg/d × 3 年，
  极高危（含破裂、核分裂 >10/50 HPF 的非胃来源）可考虑延长至 5–6 年（IMADGIST）；
  KIT exon 9 可考虑 800 mg/d；PDGFRA D842V / NF1 / SDH 缺陷型不推荐辅助伊马替尼；
  高危切除后前 2–3 年每 3–4 个月腹盆增强 CT，4–5 年每 6 个月，之后每年至 10 年。
- **CSCO 胃肠间质瘤诊疗指南 2025**：辅助治疗 6 年推荐级别上调；野生型 GIST 按 SDH / NF1 / BRAF / NTRK 四分；
  复查按危险度分层。
- **边界**：以上只用于**确定工作台记什么字段、按什么时间粒度记、哪些值要留原文**。
  工作台不复述指南推荐、不把指南条款渲染成"你应该……"，指南版本号只出现在「数据口径」与文档里。
